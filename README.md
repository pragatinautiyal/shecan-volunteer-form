# She Can Foundation – Volunteer Registration Form

A simple and responsive volunteer registration form built for the **She Can Foundation**, focused on empowering women and encouraging community participation.

---

## Features

* Clean and user-friendly UI
* Form validation using HTML5 and JavaScript
* Name validation (only letters allowed)
* Email validation (shpuld include `@`)
* Phone number validation (exactly 10 digits)
* Custom error messages
* Success message on form submission

---

## Tech Stack

* HTML5
* CSS3
* JavaScript
